Welcome to the meal service

This concept prepares individual meal containers before peak serving time. Each student initially collects one standard portion. An additional serving may be requested if food is available and mess policy permits.

No meals available

All pre-portioned meals have been collected. Please wait for restocking before trying again.

What you can do:

  • Please wait until the meals are restocked.
  • Check with mess staff if you need an update on availability.

This is a demonstration message. Actual availability would need to be confirmed by mess staff.

Screen 7 of 9 · Error state
⚠️

Additional serving unavailable

No extra food is currently available. Please wait until an additional serving becomes available.

What you can do:

  • Please wait until extra food becomes available.
  • You may continue with your standard portion if it is sufficient.

An additional serving is never guaranteed.

Screen 8 of 9 · Error state
❔

Selection not recognised

You have not selected or collected a valid meal. Please return to the meal collection screen and select a valid meal.

What you can do:

  • Return to the meal collection screen.
  • Select and collect a valid standard meal container.
  • Ask mess staff if you need assistance.
Screen 9 of 9 · Error state
🛠️

Something went wrong

A temporary technical issue is preventing the process from continuing. Please try again later.

What you can do:

  • Wait briefly and try again later.
  • Refresh the page if the problem continues.
  • Contact the project team or the relevant support person if the issue persists.

This is a simulated error state for concept testing. The prototype does not connect to a live mess system.
